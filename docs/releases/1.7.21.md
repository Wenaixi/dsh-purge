# 1.7.21

## 这一版解决什么

本版是**纯兼容性登记**，不改变插件行为：把 DSH `0.2.3-alpha.2` 列入已验证宿主，
让面板与补丁系统在启动时不再提示「未在已验证清单内」。

## 改动

| 项 | 变化 |
|---|---|
| `dsh.compatibility.dshReleases` | 新增 `0.2.3-alpha.2: compatible` |
| `@deepseek-ai/cordis` peer | `^4.0.1` → `^4.1.0` |
| `engines.dsh` | `>=0.2.2-rc.1 <0.3.0-0`（维持不变） |

宿主 0.2.3 系列随包带入 `cordis 4.2.0-alpha.1` 与 `schemastery 3.20.0-alpha.1`。

## 验证方式

- 隔离实例 `--dump-config`：零 `skipping profile bundle`、零 `ERR_MODULE_NOT_FOUND`
- 主环境实机启动：3080 监听 + 无 token 401 + token 握手后 200
- 补丁应用：cordis 4.2 下锚点未漂移

## 已知限制

- 本仓库发布权限属 `kingcharleslzy-ai/dsh-purge`，社区版按本地 tgz 分发，不走 npm registry
- 测试套件中依赖 `openssl.exe` 与 Electron 桌面版的用例在本机环境跳过或失败，与代码无关
